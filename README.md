## Agent Capability Atlas

A single-page web experience that answers “What can the agent do?” by illustrating how an autonomous partner researches, delivers, and orchestrates work for high-velocity product teams.

### Features

- Capability explorer with adjustable delivery depth and focus areas
- Operating blueprint that maps discovery, build, and enablement lanes
- Signal-to-action matrix showing proactive monitoring and responses
- Tailwind-powered dark UI with layered gradients and motion-ready components

### Development

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to view the site locally.

### Production Build

```bash
npm run build
npm run start
```

The project is ready to deploy on Vercel out of the box.
